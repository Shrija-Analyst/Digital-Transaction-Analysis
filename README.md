Digital Transaction Analysis

##  Project Overview
This project focuses on analyzing digital credit and debit transactions between senders and receivers to understand transaction behavior, revenue trends, and platform-wise performance.

The analysis was performed using Python, SQL, Pandas, and Matplotlib on transaction-level data stored in a MySQL database.


##  Objectives
- Analyze successful digital transactions
- Identify total revenue and average transaction value
- Compare transaction amounts across payment modes
- Study monthly transaction trends
- Detect high-value outlier transactions



##  Tools & Technologies
- Python
- Pandas
- MySQL
- SQLAlchemy
- Matplotlib
- GitHub


## Data Cleaning Steps
- Converted transaction date to datetime format
- Filtered only successful transactions
- Standardized text columns (status)
- Checked and handled missing values
- Identified outliers using statistical thresholds



##  Analysis Performed
- Total number of successful transactions
- Total and average transaction amount
- Platform-wise transaction volume
- Monthly transaction trends
- Detection of unusually high-value transactions
